# Proyek Web Mandiri: Aplikasi Manajer Tugas Harian

Proyek ini dibangun untuk memenuhi kriteria penugasan pengembangan aplikasi web interaktif mandiri. Aplikasi ini dirancang menggunakan prinsip UI/UX yang responsif serta menerapkan manipulasi DOM dinamis berbasis JavaScript.

## Fitur Utama Aplikasi
* **Tambah Tugas Baru:** Pengguna dapat memasukkan nama aktivitas beserta tingkat prioritasnya (Tinggi, Sedang, Rendah).
* **Manajemen Status Tugas:** Menandai tugas sebagai "Selesai" (menerapkan efek coretan teks kondisional) atau membatalkannya.
* **Hapus Tugas:** Menghapus rekaman aktivitas tertentu langsung dari daftar.
* **Penyaringan Dinamis (Filter):** Memilah tampilan daftar berdasarkan status: "Semua Tugas", "Belum Selesai", dan "Selesai".

## Teknologi yang Digunakan
* **HTML5:** Menggunakan elemen semantik standar (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer\>`) untuk struktur data yang aksesibel.
* **CSS3:** Menerapkan konsep modern layouting menggunakan **Flexbox** dan **CSS Grid** serta **Media Queries** agar tampilan web responsif (RWD) di perangkat desktop maupun mobile.
* **JavaScript (ES6):** Menggunakan struktur data *Array of Objects*, pemrosesan kondisi (*if-else*), perulangan (*looping*), fungsi modular (*arrow functions*), serta penanganan aksi pengguna (*event handling submit & click*).

## Cara Menjalankan Proyek Secara Lokal
1. Unduh atau klon repositori ini ke komputer Anda.
2. Buka folder proyek menggunakan peramban web (browser) favorit Anda dengan mengklik ganda file `index.html`.
3. Anda juga dapat menjalankannya menggunakan ekstensi **Live Server** di Visual Studio Code untuk mendapatkan fitur pembaruan otomatis.
